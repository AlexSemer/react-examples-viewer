# Vision

A gallery of modular examples with a live preview where possible and the source beside it. Start with React login, i18n, and design tokens, then widen to other stacks.

## What it is

Examples Viewer. React has a live modular login with i18n and design tokens. Next.js, Node/Express, and Python/FastAPI are listed. Sidebar navigation and a documentation page for coding standards.
